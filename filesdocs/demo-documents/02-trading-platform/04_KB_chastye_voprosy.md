# Частые вопросы по платформе «TradeFlow»

**Что происходит с ордером клиента, если во время исполнения обрывается соединение с биржевым
шлюзом?**
Ордер, уже отправленный на биржу, продолжает жить на стороне биржи независимо от состояния
соединения терминала. При восстановлении соединения платформа обязана запросить актуальный статус
всех отправленных, но не подтверждённых ордеров (order status request по FIX), а не считать их
автоматически отменёнными.

**Как считается P&L по позиции, если клиент открыл её несколькими частичными исполнениями по
разным ценам?**
Средневзвешенная цена входа по всем частичным исполнениям (Volume Weighted Average Price),
нереализованный P&L считается от этой средней цены к текущей рыночной котировке.

**Клиент без статуса «квалифицированный инвестор» пытается купить фьючерс — что должна делать
система?**
Заблокировать выставление ордера на уровне терминала (не давать даже отправить на биржу) и
показать понятное сообщение с объяснением требований для получения статуса. Список инструментов,
требующих такого статуса, ведёт отдел комплаенс — см. открытый вопрос в ТЗ.

**Что делать, если сработал Margin Call, но клиент довнёс обеспечение в течение нескольких минут?**
Margin Call снимается автоматически при пересчёте, как только уровень обеспечения снова превышает
пороговое значение — довнесение денег не требует ручного вмешательства риск-менеджера, если
процесс идёт штатно.

**Почему в стакане иногда видна котировка, которой уже нет при попытке исполнить ордер по рынку?**
Задержка между обновлением стакана на клиенте и реальным состоянием на бирже (network latency и
частота обновлений). Это нормальное поведение любого терминала — по этой причине рыночные ордера
могут исполняться по цене, отличной от последней видимой котировки (проскальзывание).

**Нужна ли отдельная авторизация для операций с крупными суммами?**
Да, для операций свыше порога, установленного комплаенс (точный порог не зафиксирован в текущем
ТЗ), предполагается подтверждение через 2FA (SMS или push) — см. раздел «Интеграции» в ТЗ.
