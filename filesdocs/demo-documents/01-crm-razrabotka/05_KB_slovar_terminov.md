# Словарь терминов — проект «CRM Кодформа»

**Лид (Lead)** — заявка потенциального клиента до момента подписания контракта.

**Воронка продаж** — последовательность стадий, через которые проходит лид: Новый → Квалификация
→ Оценка аналитиком → КП отправлено → Переговоры → Контракт подписан → Проигран.

**КП (Коммерческое предложение)** — документ с составом команды, этапами и стоимостью работ,
который отправляется клиенту.

**Milestone (этап проекта)** — блок работ с фиксированным сроком и суммой оплаты внутри проекта.

**Себестоимость проекта** — сумма (отработанные часы × внутренняя ставка сотрудника) по всем
участникам команды за весь период проекта.

**Маржинальность** — отношение (сумма контракта − себестоимость) к сумме контракта, в процентах.

**Дебиторская задолженность** — сумма неоплаченных счетов клиентами на текущую дату.

**Эскалация** — процедура уведомления вышестоящего сотрудника (руководителя, финансового
директора) при нарушении установленных сроков или показателей (см. «Правила работы команды»).

**PM (Project Manager, менеджер проекта)** — сотрудник, ведущий проект после подписания контракта.

**Источник лида** — канал, через который пришла заявка: сайт, почта, личный контакт, рекомендация,
конференция и т.д.
