# Словарь терминов — проект «СтрахПортал»

**Андеррайтинг** — процесс оценки риска и принятия решения об условиях страхования нестандартной
заявки.

**Тариф (тарифное правило)** — набор коэффициентов и условий, по которым рассчитывается страховая
премия для конкретного продукта.

**Франшиза** — часть убытка, которую страхователь покрывает самостоятельно (условная — если ущерб
меньше франшизы, выплаты нет вообще; безусловная — вычитается из любой выплаты).

**КБМ (коэффициент бонус-малус)** — коэффициент к тарифу ОСАГО, зависящий от истории аварийности
водителя (снижается при безаварийной езде, растёт при авариях по вине водителя).

**Quote (котировка)** — предварительный расчёт премии до завершения оформления полиса.

**Bind (оформление)** — финальный шаг превращения котировки в действующий полис.

**Страховой случай** — событие, предусмотренное договором страхования, с наступлением которого
возникает обязанность страховщика произвести выплату.

**Убыточность продукта** — отношение суммы выплат к сумме собранных премий за период, ключевой
показатель для актуариев при пересмотре тарифов.

**РСА (Российский союз автостраховщиков)** — профессиональное объединение страховщиков,
администрирующее систему ОСАГО, включая АИС ОСАГО.

**АИС ОСАГО** — автоматизированная информационная система, куда страховщики обязаны передавать
данные по договорам ОСАГО.

**Мегарегулятор** — Банк России в роли органа, регулирующего страховой рынок (наряду с банковским
и другими финансовыми секторами).
